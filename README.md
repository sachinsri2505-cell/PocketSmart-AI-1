# PocketSmart AI: Your Smart Budget & Expense Assistant

A GenAI-powered web application using FastAPI, Google Gemini 1.5, and Jinja2 to analyze receipts and deliver budget-based smart recommendations.

- **Backend:** FastAPI, Uvicorn
- **AI Integration:** Google Gemini 1.5
- **Image Handling:** Pillow (PIL)
- **Frontend:** Jinja2, HTML5, CSS3
- **Deployment Platform:** Render Cloud
